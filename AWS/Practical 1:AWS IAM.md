# 🧠 AWS IAM Overview

**AWS IAM** is a service used to securely control access to AWS resources.

It allows administrators to define:

```text
👤 WHO?
   ↓
IAM User

👥 WHO TOGETHER?
   ↓
IAM Group

🎭 WHAT IDENTITY?
   ↓
IAM Role

📜 WHAT PERMISSIONS?
   ↓
IAM Policy

☁️ WHAT RESOURCE?
   ↓
AWS Services
